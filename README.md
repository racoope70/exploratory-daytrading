# Exploratory Day Trading Research

> **Status: Experimental research workspace**

This repository contains early-stage quantitative trading research, prototype models, exploratory notebooks, and feature-engineering experiments.

The purpose of this repository is to evaluate modeling ideas before selected work is moved into a structured validation or implementation workflow.

## Scope

This repository includes:

- Exploratory model development
- Feature-engineering experiments
- Early backtesting and signal-generation tests
- Learning-stage notebooks and prototype code
- Research outputs retained for development history

Notebooks and scripts in this repository are not expected to be fully standardized. Some files are intentionally left in their original exploratory form to preserve the research path and show how model ideas evolved.

## Project Flow

1. **Exploration**  
   Initial research, prototype models, feature experiments, and exploratory results.

2. **Validation**  
   Selected models are moved into a structured workflow for walk-forward testing, backtesting, and paper-trading evaluation.  
   - [quant-trading-model-validation](https://github.com/racoope70/quant-trading-model-validation)

3. **Implementation**  
   Validated work is refactored into a cleaner implementation pipeline.  
   - [ppo-trading-pipeline](https://github.com/racoope70/ppo-trading-pipeline)

## Disclaimer

This repository is for research and educational purposes only.

The code, notebooks, results, and models may be incomplete, unvalidated, or unsuitable for live trading.

Nothing in this repository should be interpreted as financial advice or as a recommendation to trade financial instruments.
