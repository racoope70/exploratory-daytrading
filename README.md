# Exploratory Day Trading Research

> **Status: Experimental Research Workspace**

This repository contains early-stage trading research, exploratory notebooks, prototype models, and feature-engineering experiments.

It is used to evaluate initial ideas before selected work moves into model validation and implementation.

## Project Flow

1. **Exploration:** exploratory research, notebooks, and prototype ideas  
2. **Validation:** model development, backtesting, and paper testing  
   - [quant-trading-model-validation](https://github.com/racoope70/quant-trading-model-validation)
3. **Implementation:** reproducible PPO trading pipeline  
   - [ppo-trading-pipeline](https://github.com/racoope70/ppo-trading-pipeline)

## Disclaimer

This repository is experimental and educational only.  
The code and models may be incomplete, unvalidated, or unsuitable for live trading.

Nothing here should be interpreted as financial advice.
